## 下一步建议（未自动承诺实现）

1. **优先接入用户实际样本**：分类记录载体、格式、分卷命名、加密类型、预期输出层次；先复现再确定是否属于已支持范围。通过最小合成样本补回归，避免公开私人数据。
2. **补足发布前人工验收**：在目标用户 Windows/macOS 环境验证拖放、TXT 导入、取消后继续、长路径、较大文件及剩余磁盘不足等场景；现有 CI 未覆盖所有系统版本和交互。
3. **正式分发准备**：首次自动 Release 已成功；Windows 签名、Apple Developer ID/公证仍未配置，须另行确定。
4. **遇到真实需求再评估扩展**：非标准分卷、更多伪加密、跨重启恢复、密码安全存储。需要先明确行为和兼容策略；不顺带加入顶层批量或自动补卷。

## 已知限制与验收缺口

- 像素隐写、RAR/7z 特殊伪加密及任意改名/每卷独立拼接载体的分卷不承诺支持。
- 任务缓存无跨重启自动加载器；密码保存在本机明文 JSON。
- 路径/链接检查及递归数量限制不是完整磁盘配额或沙箱；大文件性能与空间压力没有量化基准。
- 结果发布按文件移动并尝试失败回滚，不是支持进程崩溃恢复的完整事务。
- 密码错误与加密损坏可能显示相同提示；UTF-8 回退受 `pyzipper` 支持的方法限制。
- GUI 自动测试不覆盖全部对话框交互；成品截图证明当次渲染，不证明所有 DPI、主题和系统字体组合。
- macOS 支持目标为 14+，CI 验证环境是 macOS 15；最低目标版本未单独实机验收。
